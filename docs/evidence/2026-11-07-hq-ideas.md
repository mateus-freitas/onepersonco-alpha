# HQ Ideas — OPC-35 through OPC-39

Implemented a separate Ideas area, deterministic `opc idea` store/CLI/API,
revision-safe edits, source-backed qualitative comparisons and the installed
`opc-idea` capture/research skill. Vanilla HTML/CSS/JS and existing theme retained.
The store is private JSON outside git, with Markdown export; no database added.

Only Gymbloc and skincare adaptation were imported. Gymbloc links to the existing
project. Both original narratives were checked byte-for-byte against the owner's
notes. The pilot has 28 measured US-English keywords across two Wow Keywords
brainstorms. These are scoped proxies, not Apple search counts or validated demand.
Detailed ASO remains in Wow Keywords. Additional ideas await owner pilot approval.
