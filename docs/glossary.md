# Glossary

Shared vocabulary. Add a term only when it would be used wrongly without it —
this is not a feature index.

- **Hub** — this repository (`~/dev/onepersonco-alpha`); the control room. Never
  contains project code.
- **Standards** — the rule fragments in `standards/`; the single place a shared
  rule is edited.
- **Managed block** — a region of a project's `AGENTS.md` between `opc` markers,
  generated by `opc sync`. Never hand-edited.
- **Project** — a repository registered in `projects.json` (blocos, gymbloc, or
  the hub itself).
- **Scratch** — `~/dev/.onepersonco/`; per-project working memory (prompts,
  active plans, research notes, artifacts, trash). Never committed, safe to
  delete, not a source of truth. Durable knowledge graduates into a repo.
- **Backlog line** — one line in a project's `docs/backlog.md`; the only task
  format agents write.
- **Console** — the local web app (`opc console`) that scans projects + scratch
  and renders the kanban board, worktrees, RFCs, prompts and evidence views.
- **Board** — the kanban view (tab) inside the console.
- **opc** — the CLI in `scripts/` (sync · check · scan · console; `new` comes
  with the skeleton).
